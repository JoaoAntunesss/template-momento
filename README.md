# Template Momento

Site para fotógrafos, criadores de conteúdo e organizadores de eventos (casamentos, batizados, aniversários): portefólio em 3D, pedido de orçamento e área de cliente privada com mensagens, notas para o dia, ficheiros e entregas por WeTransfer. Firebase (Realtime Database, Auth, Functions).

**Demonstração:** https://joaoantunesss.github.io/template-momento/ · área de cliente com o código `DEMOANAPEDRO`.
